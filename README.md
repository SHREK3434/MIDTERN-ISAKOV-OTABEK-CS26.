# Проект: «Инженерный колледж» — Статический многостраничный веб-сайт

## Обзор проекта и Карта страниц
Данный веб-сайт создан в качестве экзменационного проекта. Он представляет собой адаптивный статический многостраничный веб-сайт для Инженерного колледжа, содержащий удобную навигацию и доступные интерфейсы.

### Карта страниц:
1. `index.html` — Главная страница с призывом к действию и основными преимуществами.
2. `about.html` — О программах обучения с динамическим поиском.
3. `admissions.html` — Приемная комиссия, этапы, таблица цен и FAQ.
4. `campus.html` — Студенческая жизнь, клубы и новости.
5. `contact.html` — Контакты и форма обратной связи с проверкой на спам.
6. `register.html` — Расширенная форма предварительной регистрации абитуриента.

## Реализованные функции
- **Адаптивный UI/UX**: Разметка на Bootstrap 5 с поддержкой мобильных устройств, планшетов и ПК.
- **Доступность (a11y)**: Семантический HTML5, поддержка управления с клавиатуры (visible focus outlines), правильное связывание `label` и `input`, ARIA-атрибуты.
- **Валидация форм**: Клиентская проверка в `register.html` и `contact.html` с выводом понятных сообщений об ошибках и защитой от спама.
- **Два JavaScript-взаимодействия**:
  1. **Интерактивный поиск/фильтрация программ** (`about.html`): динамическая фильтрация карточек программ на лету.
  2. **Интерактивный аккордеон FAQ** (`admissions.html`): удобный просмотр часто задаваемых вопросов.

## Известные ограничения
- Сайт является статическим и не содержит бэкенд-обработки данных (данные форм обработаны только на стороне клиента без отправки на сервер).

## Указание авторства
- Фреймворк: [Bootstrap 5.3](https://getbootstrap.com/)
- Шрифт: Системный стек шрифтов Segoe UI / Sans-serif.
